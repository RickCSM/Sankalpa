# Sankalpa Odisha

Non-Docker deployment of Sankalpa Odisha using Node.js, PostgreSQL, Nginx and systemd.

See [DEPLOYMENT.md](DEPLOYMENT.md) for installation, HTTPS configuration, updates and troubleshooting.

The application includes the standardized PDF/Excel report exports and vertically centered PDF filter text.

Database contents, user uploads, secrets and built files are not included. The previous Docker deployment remains available in Git history.
